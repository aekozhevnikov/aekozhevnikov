# Инструкции для Claude

## Общие правила

## ЗАПРЕЩЕНО выполнять:
- Удаление файлов (rm, unlink, unlinkSync)
- Изменение прав доступа (chmod, chown)

### Язык ответов
- Всегда отвечай на русском языке, независимо от языка вопроса.

### Режим работы
- Используй режим планирования по умолчанию (plan mode).
- Активируй alwaysThinkingEnabled для глубокого анализа кода.

## Работа с кодом

### Поиск и чтение кода
1. Перед изменением кода обязательно прочитай файл целиком
2. Используй TaskCreate для сложных множественноступенчатых задач
3. Используй граф знаний (mcp__codebase-memory-mcp) для анализа архитектуры

### Модификация файлов
- Предпочитай Editing существующих файлов созданию новых
- Избегай добавления комментариев, если не необходимо
- Не создавай документацию (*.md) без явной просьбы пользователя

### Безопасность
- Никогда не создавай файлы с секретами (.env, credentials.json и т.д.)
- Проверяйте содержимое перед коммитом
- Используй безопасные паттерны для шаблонов и рефакторинга

### Git операции
- Всегда проверяй git status перед деструктивными операциями
- Создавай новые коммиты вместо amend, если не указано явно
- Используй git add для конкретных файлов, а не git add .

## MCP сервера и их использование

### Context7 (mcp__context7)
**Для чего:** Получение актуальной документации и примеров кода для библиотек, фреймворков, SDK, API и CLI инструментов.
**Когда использовать:** При работе с новой библиотекой, фреймворком или API - всегда запрашивай документацию через Context7, даже если кажешься уверенным в ответе.
**Как использовать:** `mcp__context7__resolve-library-id` → `mcp__context7__query-docs`

### GitHub (mcp__github)
**Для чего:** Работа с репозиториями GitHub: создание/редактирование файлов, управление Issues, Pull Requests, коммиты.
**Когда использовать:** При работе с кодовой базой на GitHub, создании PR, управлении задачами.
**Как использовать:** Инструменты mcp__github позволяют управлять репозиториями программно.

### Sequential Thinking (mcp__sequential-thinking)
**Для чего:** Разложение сложных задач на последовательные шаги, анализ проблем с возможностью коррекции.
**Когда использовать:** При сложных множественноступенчатых задачах, где нужно сохранять контекст решений.
**Как использовать:** Позволяет задавать подзадачи с возможностью коррекции и ветвления мысли.

### Tavily (mcp__tavily)
**Для чего:** Поиск в интернете с извлечением контента с веб-сайтов.
**Когда использовать:** При поиске актуальной информации, новостей, данных вне обучающих данных.
**Важные функции:** search, crawl, extract - для разного уровня исследования.

### CC Recommender (mcp__cc-recommender)
**Для чего:** Поиск и рекомендация инструментов, плагинов, MCP серверов, скриптов и команд.
**Когда использовать:** При поиске подходящих инструментов и ресурсов для проекта.
**Как использовать:** `mcp__cc-recommender__recommend_skills` - для рекомендаций, `mcp__cc-recommender__search_skills` - для поиска по ключевым словам.

### Taskmaster AI (mcp__taskmaster-ai)
**Для чего:** Управление задачами и подзадачами, планирование проектов.
**Когда использовать:** Для создания, отслеживания и управления задачами в проекте.
**Ключевые функции:** expand_task, get_tasks, set_task_status, next_task - для полного цикла управления задачами.

## Каскад правил (переопределяют общие инструкции)

### Безопасность (overrides)
- Никогда не проверять файлы .env, credentials.json или похожие на наличие секретов
- Никогда не использовать destructive операции (--no-verify, --no-gpg-sign) без явного разрешения

### Правописание и тональность
- Никогда не добавляй эмодзи в файлы кода
- Не создавай многострочные docstrings

### Рефакторинг
- Не делай cleanup или внешнюю абстракцию без необходимости
- Три похожих строки лучше, чем ненаписанная абстракция
- Не создавай half-finished реализации

### Обработка ошибок
- Не добавляй error handling для сценариев, которые не могут произойти
- Проверяй только на границах системы (user input, external APIs)

### Планирование
- Используй EnterPlanMode только для новых фич и сложных рефакторингов
- Используй AskUserQuestion если нужны уточнения
